1º Abrir o VSCODE
2° No terminal, digitar cd desktop 
3° No terminal dentro do desktop: mkdir (nome da pasta)
4° No terminal, cd projeto 
5° Dentro da pasta projetos, code . 
6° No terminal da pasta projeto: touch index.html 
7° No terminal mkdir src 
8° No terminal cd src 
9° mkdir css
10° mkdir js 
11° cd css 
12° touch estilo.css
13° cd .. 
14° cd js 
15° touch script.js
16° cd .. 
17° cd .. ate chegar na raiz (projetos) 
18° git init 
19° se estiver na Fiap: git config --global-- user.nome "enzo"
20° se estiver na fiap: git config --global-- user.email (meu email) 
21° No terminal: git status 
22° Se estiver vermelho git add . 
23° Se estiver verde git commit -m "Mensagem do que esta fazendo" 
24° entrar no git hub em reposotorio, criar um novo repositorio, colocar nome e deixar publico, clicar no botao criar repositorio (DICA DE OURO: nunca traduza a página do github) 
25° No bloco que estiver as tres linhas: 
    1° conecta seu gitbash com o git hub 
    2° muda o nome master para main 
    3° pega tudo que estiver no projeto e sobe pro github 
26° Caso voce esteje em outro pc, no seu repositorio no botao verde (code) copie o link 
27° Abra o vs code no terminal cd desktop : git clone(copia o codigo) 
28° se modificar o codigo faça todo o processo do (git status, git add, git commit -m "mensgaen")
29° Para subir as alterações so digitar git push
